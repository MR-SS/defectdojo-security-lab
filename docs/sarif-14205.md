## Entrypoint and safeguards

`tests/integration/test_sarif_identity.py::test_sarif_identity` requires both
DDSLAB_RUN_INTEGRATION=1 and DDSLAB_APPROVE_SCENARIO=SARIF-14205. Never set these
for offline testing. Existing private credentials, loopback URL, Product Type 3
and pinned source checkout are required. The test checks configuration before
mutation, creates isolated context, issues one import/reimport, records intents,
responses and checksums, requires synchronous completion, reads all findings,
and does not retry or delete records. Evidence preserves partial failures.
Fresh readiness, source/image correspondence and effective created-Test matching
configuration must be confirmed before a separately approved live run.
